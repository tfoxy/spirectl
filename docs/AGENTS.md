# docs/AGENTS.md

## Purpose

Docs should make the project usable by:

- human developers
- AI agents
- future contributors

---

## Rules

### Keep docs aligned with reality

If a command changes, examples and help-oriented docs should be updated promptly.

### Prefer examples

Show command usage, output shape, and workflows.

### Document schemas and modes

State shape, action semantics, normal/dangerous modes, and config behavior should be clear.

### Support AI-skill future

Docs should make it easy to understand how the tool can be consumed programmatically.

---

## Avoid

- aspirational docs that diverge from implementation
- prose without examples for complex command behavior
